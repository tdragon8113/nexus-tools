# 「统计」页面 — 内容方案（已确认）

日期：2026-06-26  
页面：`/prototypes/time-journal#page=stats`

## 用户确认

- **核心问题**：这段时间时间主要花在哪（类型 + 活动明细）
- **主视图**：一天的时间结构（四段）+ 按天彩色条 / 时间轴（方案 1+2）
- **时段划分**：深夜 0–6 / 上午 6–12 / 下午 12–18 / 晚上 18–24
- **时间范围**：顶部 Chip（今天 / 昨日 / 本周 / 本月 / 近7天 / 近30天 / 自定义）

## 页面结构

1. 时间范围 Chip + 摘要（总时长、条数、对比）
2. **一天的时间结构**（四段横向条 + 类型分色）
3. **类型分布** chips（可高亮筛选，支持不含睡觉）
4. **每日概览**：彩色日条 → 点某天展开活动 time 轴 → 可进详情

## 设计决策

- 收拢为单一统计内容结构（不再切换四种布局方案）
- 与首页差异：统计页提供 **跨多天** 的时段汇总 + **逐日** 时间轴
